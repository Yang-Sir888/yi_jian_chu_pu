# 独立评审入口部署

2026-11-10：用户确认原 chatgpt.site 地址在电脑与手机移动数据下均出现 Cloudflare 拦截页。原托管站点仍为 active/public，测试出口的成功访问不能证明评审网络可达。现有 Sites 工具不能编辑平台 WAF 规则。旧地址暂不作为可靠评审入口，重新部署或改密码不构成对此问题的修复。

## 已准备的替代方案

- 使用现有 GitHub 源码，通过 Render 运行 Node.js 22 + Express。
- 地区：Singapore；单实例，0.5 CPU / 512MB；1GB 持久磁盘挂载到 /var/data。
- PGlite 数据、作品、账号和密钥主密钥保留在持久存储；音频容量限制512MB，预留数据库与日志空间。
- 首次账号密码从 Render Secret 中注入，代码和构建日志不包含真实密码。已有账号不会随环境密码变更而重置。
- 系统自动采用 Render 分配的正式 HTTPS URL 校验来源，无需事先猜测域名。
- 百炼仍由管理员配置一次，其他账号无需配置；独立部署不会自动复制旧 D1 数据库与已有百炼密文，迁移已有数据需要另行核实。
- 禁止自动部署，更新由项目所有者控制。

配置文件：根目录 render.yaml。已使用 Render 官方 JSON Schema 通过结构校验；账号首次初始化与重启保留的3项真实子进程测试通过。尚未创建 Render 资源或完成其云端构建，不能把配置准备完成称为部署成功。

## 成本和批准

预计基础费用约7.25美元/月：Web实例7美元/月，1GB持久磁盘0.25美元/月。以创建时控制台报价为准，可能另计超额流量、税费与百炼API调用费用。免费实例不能挂本方案必需的持久磁盘，不应用来保存账号、作品和密钥。

本文件和 render.yaml 仅准备配置，不会自动创建或购买服务。必须先由用户连接自己的 Render 账号，并明确确认上述付费方案，再创建资源。首次部署需要给 ADMIN_PASSWORD / EXPERT_PASSWORD 提供12–128字符的秘密值，或通过已连接工具安全设置。

## 启动部署

[从现有仓库打开 Render 部署配置](https://render.com/deploy?repo=https%3A%2F%2Fgithub.com%2FYang-Sir888%2Fyi_jian_chu_pu)

登录并核对计划、地域、磁盘和费用；不要把创建向导地址当作已部署网址。部署成功后由平台返回实际 onrender.com 地址，再分别验证健康接口、登录、音频识别、保存重开、原音读取和导出。最终还需由用户的电脑和移动网络测试，确认后才作为评审提交地址。

如果 Render 账号或费用尚未就绪，可在本机运行 start.bat，访问 http://localhost:3000。该地址只在本机有效，不能发给远程评审。
