# 历史沙箱部署说明

本文件原用于旧 WorkBuddy/CloudStudio 沙箱环境，涉及的平台代理、云环境标识、数据库通道和平台发布入口，不适用于当前交付。请勿按照旧沙箱地址配置正式网站，也不要将环境秘密或账号密码写入源码。

当前云端使用 Sites 托管的 Cloudflare Worker、D1 数据库和私有 R2；本地使用 Express 与持久化 PGlite，亦可连接独立 PostgreSQL。安装、环境变量、数据库迁移、账号初始化、共享百炼密钥和更新流程，统一以根目录 [DEPLOY.md](../DEPLOY.md) 为准。

实际专家网址与账号由当前交付记录提供。GitHub 仓库保存代码，不能替代专家访问入口；构建成功或发布成功，也不能替代公网登录、保存、重开与识别流程验证。
